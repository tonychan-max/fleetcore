# 0006. 再送方針を電文定義に持たせる

## 状態

**提案** — 2026-08（Phase 3 で着手予定。未実装）

## 背景

ARCHITECTURE §3-6 で「上りは落としてよい、下りは落としてはいけない」と決めた。
しかしこの方針は現在どこにも記述されていない。実装者の記憶の中にしか無い。

電文が増えたとき、どれを再送し、どれを捨ててよいかを
**各プロセスの実装者が個別に判断する**ことになる。判断がズレたときに気づく手段が無い。
