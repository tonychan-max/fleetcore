# 0000. （題：何を決めたかを一文で。体言止めにしない）

## 状態

採用 / 提案 / 却下 / 廃止（ADR-XXXX により置換） — YYYY-MM-DD

> **採用** = 実装済み、または着手が確定している
> **提案** = 方針は決めたが未実装。後で覆る可能性がある
> 未実装のものを「採用」と書かない。これを守らないと ADR が信用を失う。

## 背景

なぜ今この判断が必要になったのか。制約は何か。
**将来の自分が文脈ゼロで読むことを想定して書く。**

## 選択肢

1. 案A — 概要
2. 案B — 概要
3. 案C — 概要

**検討したが早期に外したもの**も1行で残す。「なぜ検討しなかったのか」を後で聞かれるため。

## 決定

（選んだもの）

## 理由

- 箇条書きで。優先順位の高い順
- 「なんとなく」は書かない。書けないなら判断がまだ固まっていない

## 代償

**必ず書く。** 代償の無い設計判断は存在しない。
書けない場合は選択肢の検討が不十分。

  → 対策（あれば）
